How it works

Everything saves to the server straight away and shows up on every device. Made a mistake? Tap Undo on the pop-up, or open History.

Search

Type any part of a name, category or note. Small typos still work (“fevikwik”, “micro usb cble”). Type box 3 to jump to a box.

Adding

If something similar already exists, the form shows it so you can add +1 instead of creating a duplicate. Scanning a box label opens that box.

Labels

The red number on Labels counts boxes whose contents changed since you last printed their label.

Android app

Install the app from inventory.refurbindia.com/app.html to scan labels with your camera and use it offline.
